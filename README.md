X-Learn AI

AI-Powered Fracture Detection and Interactive Learning Platform

Overview

X-Learn AI is an educational deep learning application designed to assist students in understanding fracture identification using X-ray images. The platform combines AI-based fracture detection with interactive quiz-based learning to create a more engaging and practical educational experience.

The system uses a Convolutional Neural Network (CNN) trained on labeled X-ray datasets to classify images into:
Fractured
Non-Fractured

Features:
1.Doubt Solver
Upload X-ray images
AI-based fracture classification
Real-time prediction
Educational support for fracture understanding

2.Quiz Mode
Interactive fracture identification quizzes
Difficulty levels:
Easy
Medium
Hard
Timer-based assessment
Score tracking system
Practice using real X-ray images
